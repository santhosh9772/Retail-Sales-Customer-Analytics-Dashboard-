# 🛒 Retail Sales & Customer Analytics Dashboard – Excel
📌 Project Overview

This project is an Excel-based Retail Sales & Customer Analytics Dashboard created to analyze 10,000 retail transactions and generate meaningful business insights.

The project covers data analysis, KPI calculations, Pivot Tables, sales analysis, profit analysis, customer analytics, payment methods, shipping methods, and return analysis.

The main objective is to convert raw retail data into useful business insights using Microsoft Excel.

🎯 Project Objectives
  1). Analyze overall retail sales performance
  2). Identify the highest and lowest performing categories
  3). Analyze product-wise sales and profit
  4). Compare regional performance
  5). Analyze monthly sales trends
  6). Understand customer payment preferences
  7). Analyze shipping methods
  8). Calculate return rate
  9). Identify top-selling and most profitable products
  10).Create an interactive Excel dashboard
  11). Generate business insights from sales data
